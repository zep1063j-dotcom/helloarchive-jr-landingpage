# Hello Archive jr

텍스트 중심 자녀 성장 기록 서비스의 출시 알림 랜딩페이지입니다. 외부 빌드 도구 없이 실행되며, GitHub 업로드와 배포는 사용자가 직접 진행합니다.

## 파일

- `index.html`: 전체 콘텐츠, 시맨틱 구조, SEO·Open Graph 메타 태그
- `css/style.css`: 아이보리·블랙·레드 디자인, 반응형 레이아웃, 모션 감소 지원
- `js/config.js`: 모든 출시 알림 버튼에서 공유하는 실제 Google Form URL
- `js/main.js`: 연령 탭/키보드 이동, 기록 체험, CTA 설정 검증, 스크롤 모션
- `assets/og-image.svg`: 공유 이미지 원본. SNS별 SVG 지원 차이가 있으므로 공개 배포 전 PNG로 변환하고 `og:image`를 최종 절대 URL로 변경 권장
- `.nojekyll`: GitHub Pages 정적 파일 제공 설정

## 실행

이 폴더에서 실행:

```sh
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. 설치나 빌드가 필요하지 않습니다. `index.html` 직접 열기도 가능합니다. 폰트는 Google Fonts에서 불러오며, 접속이 안 되면 시스템 폰트를 사용합니다.

## GitHub Pages에 직접 배포

1. 이 폴더의 파일을 저장소 루트에 올립니다. `css`, `js`, `assets` 폴더 구조를 유지하세요.
2. 저장소 Settings → Pages → Deploy from a branch에서 업로드한 브랜치와 `/ (root)`를 선택합니다.
3. 공개 URL이 생성되면 OG 이미지 URL을 해당 도메인의 절대 주소로 바꾸고 실제 모바일 기기에서 확인합니다.

Git 초기화, 커밋, 푸시, 원격 배포는 수행하지 않았습니다.

## 구성 및 기존 페이지 개선

7개 콘텐츠 그룹: Hero / Why / 같은 질문·다른 나이 / 3단계 이용 방법 / 기록 체험 / 기록집·미래 기능 / FAQ·마지막 CTA. 마지막 그룹은 접근성과 배경 전환을 위해 두 HTML section으로 나누었습니다.

기존 사이트의 종이와 책 중심 에디토리얼 감성을 유지했습니다. 올리브·샌드 중심의 기존 팔레트는 요청한 블랙·레드·아이보리로 재구성했습니다. 긴 문제 제기와 연령별 설명은 짧은 공감 문구 및 6·10·15세 탭으로 통합했습니다. 기간별 장문의 상품 설명은 3개 표지 카드로 묶었고, FAQ는 5개로 정리했습니다. 목업과 답변은 모두 가상 예시이며, 미래 기능과 PDF·실물 책은 확정 서비스처럼 표현하지 않습니다.

## 신청 주소

기존 공개 사이트 `js/config.js`의 Google Form 주소를 보존했습니다. HTTP 200 응답과 페이지 제목 `Hello Archive jr 출시 알림 신청`을 확인했습니다. 광고 관리자에는 접근하지 않았으므로 실제 광고 최종 도착 주소와의 일치 여부는 운영자가 확인해야 합니다.

주소 변경은 `js/config.js`의 `GOOGLE_FORM_URL` 한 곳에서 합니다. 비어 있거나 허용된 Google Form 주소가 아니면 모든 CTA는 준비 중 안내를 표시하며 신청 접수로 오인시키지 않습니다. Google Form은 새 탭에서 열립니다.

## 개인정보 및 데모

데모는 브라우저 메모리와 DOM에서만 동작합니다. 기록을 전송하는 fetch·분석 이벤트·서버·쿠키·로컬 저장소가 없습니다. 새로고침 시 입력이 사라집니다. Google Fonts 요청에는 데모 입력을 포함하지 않습니다. 실제 신청 정보 수집은 연결된 Google Form에서 이루어지므로 폼의 개인정보 안내와 접근 권한은 운영자가 관리합니다.

## 검증

- JavaScript 두 파일 `node --check` 통과
- HTML ID 중복 없음, 내부 앵커 대상 존재 확인
- 로컬 HTTP 서버 및 데스크톱 브라우저 렌더링 확인
- 10세 클릭, 오른쪽 방향키를 통한 15세 전환과 답변·부모 메모 교체 확인
- 기록 입력 → 결과 카드 → 재작성 → 다른 질문 전환 확인
- 4개 출시 알림 링크의 동일한 Google Form URL 및 새 탭 설정 확인
- 실제 Google Form HTTP 200 및 신청 페이지 제목 확인, 응답 제출은 수행하지 않음
- 360px 이하 / 700px 이하 / 1000px 이하 CSS와 모션 감소 대응 구현
- 실제 모바일 기기 및 모든 브라우저에서의 시각 검증은 미수행. 배포 전 iOS Safari·Android Chrome에서 확인 권장
